LabelWorkspace 组件依赖图
┌─ LabelWorkspace ────────────────────────────────────────────────┐
│                                                                 │
│  ┌─ AssetListPanel ─┐  ┌─ LabelingWidget (embedded) ─┐  ┌─ Inspector ─┐  │
│  │ - 资产列表         │  │ - Canvas (标注画布)          │  │ - 属性显示   │  │
│  │ - 标注状态图标      │  │ - ToolBar (形状工具)         │  │ - 标签编辑   │  │
│  │ - 搜索/筛选        │  │ - LabelFile → AnnotationDocument│  │ - 坐标查看   │  │
│  │ - 进度统计         │  │        ↕ AnnotationAdapter   │  │              │  │
│  └──────────────────┘  └──────────────────────────────┘  └─────────────┘  │
│                                                                 │
│  Uses: AnnotationService (XLabelCodec)                           │
│  Uses: ProjectFileStore (labels, task_spec)                      │
│  Connects: asset_selected → LabelingWidget.load_image()          │
│  Connects: annotation_changed → AnnotationService.save()         │
└─────────────────────────────────────────────────────────────────┘
