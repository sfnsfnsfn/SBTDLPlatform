LabelWorkspace v2 — 任务驱动的标注工作区

完整保留 Canvas 交互 · 按 Task Family 筛选工具 · 标注增删改

设计原则

1. 不修改 Canvas 内部交互 — 保留所有原始行为（跟随鼠标画 polygon、顶点吸附、右键菜单等）
2. 任务驱动工具筛选 — 根据 TaskSpec.family 控制工具栏可见项，非当前任务标注方式自动隐藏
3. 标注增删改 — 删除（Delete键/右键菜单）、修改（双击编辑/拖拽顶点）、属性编辑（检查器面板）

Task Family → 标注工具映射

不同任务类型显示的标注工具栏
Task Family 可用工具 geometry_type 说明
classification (image_labels) 仅图像级标签，无形状工具
detection_hbb bbox_xyxy 仅水平矩形框
detection_obb obb_polygon 有向边界框(4点)
instance_segmentation polygon 多边形分割标注
pose keypoints 人体/物体关键点
semantic_segmentation polygon / raster_mask 语义分割(多边形+掩码)
anomaly bbox_xyxy / polygon 异常区域标注

标注操作：增删改

➕ 新增标注
  • 选择对应工具 → 在画布上绘制
  • 检测到 polygon 绘制中时：跟随鼠标显示实时预览线段
  • 绘制完成后弹出标签选择对话框
  • 新建的 Shape → AnnotationObject(新UUID)
  • 自动保存到 annotations/{asset_id}.json
🗑️ 删除标注
  • 快捷键 Delete — 删除选中标注
  • 右键菜单 — "删除标注"
  • 批量删除 — 框选多个 → Delete
  • 删除后即时保存（覆盖 JSON）
  • 支持 Undo (Ctrl+Z) 恢复
✏️ 修改标注
  • 拖拽顶点 — 调整形状
  • 拖拽整体 — 移动标注位置
  • 双击 — 编辑标签类别
  • 检查器面板 — 修改属性
  • 修改后即时保存

AnnotationAdapter — 桥接层设计

Shape ↔ AnnotationObject 双向转换，不改动 Canvas 内部
# 标注加载流程
LabelingWidget.loadFile(image_path)
  → AnnotationAdapter.load(asset_id)
    → AnnotationService.load_annotations(ann_path, w, h) → AnnotationDocument
    → AnnotationDocument.objects → LabelingWidget.shapes  # 只注入形状数据

# 标注保存流程（形状变更时自动触发）
LabelingWidget.shapes_changed
  → AnnotationAdapter.save(asset_id, shapes)
    → shapes → AnnotationObject 列表 → AnnotationDocument
    → AnnotationService.save_annotations(doc, ann_path)

# 任务驱动工具筛选
LabelWorkspace.set_task_spec(task_spec)
  → 根据 task_spec.family 计算 allowed_geometry_types
  → LabelingWidget.set_allowed_shape_types(allowed_types)
  → Canvas 工具栏根据 allowed_types 显示/隐藏按钮
  → Canvas._create_mode 限制为允许的类型
