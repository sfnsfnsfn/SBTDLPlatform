# X-AnyLabeling 视觉算法平台 — 产品交互方案优化

**版本**: v1.0
**日期**: 2026-06-07
**定位**: 离线单机一站式深度学习平台 — 标注、训练、验证、导出、部署
**参考平台**: MVTec HALCON Deep Learning Tool · 海康机器人 VisionTrain · 阿丘科技 AIDI · Ultralytics YOLO Platform

---

## 1. 竞品交互逻辑提取

### 1.1 四大平台共识：七步流水线

```
HALCON:       标注 → 训练 → 评估 → 部署
VisionTrain:  数据准备 → 数据标注 → 训练 → 评估 → 部署
AIDI:         创建工程 → 加载图像 → 算法画布 → 标注 → 训练 → 评估 → 导出
YOLO:         上传数据 → 标注 → 数据集版本 → 训练 → 验证 → 导出
```

**共同模式**:

| 步骤 | HALCON | VisionTrain | AIDI | YOLO | 我们的方案 |
|------|--------|-------------|------|------|-----------|
| 创建项目 | 独立向导 | 方案管理 | 工程+算法画布 | 项目/数据集 | 轻量两步 |
| 导入数据 | 文件夹自动标注 | 数据集导入裁剪 | 支持3万×3万大图 | CAS去重存储 | 拖拽导入+大图检测 |
| 数据标注 | easyTouch交互 | 预标定+智能标定 | 在线标注工具 | SAM智能标注 | 智能预标注+自动追加 |
| 大图处理 | 内置ROI | 图片裁剪功能 | 视图传递 | 无 | SAHI切片+合并 |
| 训练参数 | 独立参数面板 | 参数推荐 | 训练助手推荐 | 超参调优面板 | 参数推荐+独立配置 |
| 模型验证 | 混淆矩阵+热力图 | Loss曲线 | 混淆矩阵+得分分布 | 全面指标 | 指标+热力图+对比 |
| 模型导出 | dlmodel格式 | VisionMaster导入 | VS工程导出 | 13种格式 | 多格式+SDK包 |

### 1.2 各平台关键交互亮点

#### HALCON — 专业级深度学习的"工业标准"
- **文件夹自动标注**: 按文件夹名=类别名，导入即标注（分类任务）
- **easyTouch 拖拽**: 框选→标注一气呵成，减少点击次数
- **Deep OCR 标注提案**: 系统预标注→人工确认/微调
- **Grad-CAM 可视化**: 推理时显示模型关注区域
- **独立步骤但可跳转**: 标注/训练/评估三区可自由切换

#### VisionTrain — "三步训练"的极致简流
- **三步训练**: 选模型→配参数→启动，二三级界面一目了然
- **参数智能推荐**: 基于样本数量/尺寸/类别数自动推荐
- **边缘学习**: 1-5张即可训练（小样本场景）
- **模型加密**: 导出模型可设密码保护
- **排队训练**: 支持多个训练任务排队执行
- **不足**: 模型能力仅小/中/大三级，无法自定义网络结构；无验证集切分

#### AIDI — 算法画布的"零代码编排"
- **算法画布**: 可视化拖拽算法模块，串行/并行/汇总编排
- **训练助手**: 智能推荐训练集，增量训练综合提速70%
- **综合判定**: 位置/数量/阈值/逻辑判定，勾选即完成
- **AI缺陷生成器 (AIDG)**: 基于少量缺陷样本生成更多变体
- **工厂模式**: 模拟产线运行，批量验证模型效果
- **一键导出**: 自动生成 VS 工程（C++/C#/Python）

#### YOLO Platform — 云端数据管理的"完整闭环"
- **CAS 去重存储**: XXH3-128 哈希，相同图片只存一次
- **数据集版本快照**: NDJSON 不可变快照，训练可复现
- **数据统计面板**: 切分分布/类别计数/热力图/维度分布/聚类
- **SAM 智能标注**: SAM 2.1 + SAM 3 加速标注
- **13种导出格式**: ONNX/OpenVINO/CoreML/TensorFlow/Paddle/TensorRT...
- **不足**: 云端依赖，离线单机场景不适用

## 3. 优化方案：八步流水线

### 3.1 设计原则（提取自竞品 + 离线单机约束）

| 原则 | 来源 | 含义 |
|------|------|------|
| **渐进式披露** | AIDI + VisionTrain | 简单先呈现，复杂后展开 |
| **步骤解耦** | HALCON 独立工作区 | 每步独立，可跳转、可回退、可重做 |
| **数据优先** | 四平台共识 | 先看到数据，再做决策 |
| **可逆决策** | 竞品对比得出 | 任务类型/标签/参数均可事后修改 |
| **预览驱动** | HALCON + YOLO | 每步提供可视化反馈 |
| **智能推荐** | VisionTrain + AIDI | 基于数据特征自动推荐参数 |
| **离线优先** | 本方案约束 | 零网络依赖，JSON文件存储，无数据库 |
| **单机高性能** | 本方案约束 | 本地GPU推理/训练，SAHI大图处理 |

**交互特性**:

|------|----------|----------|

- 文件复制到 `assets/` 目录
- 自动检测重复（SHA-256）
- 图像属性预分析（尺寸/通道/位深/格式）
- 大图标记（触发后续切片建议）
- 可选：从标注文件解析已有标签

**切片后标注处理规则**:

| 场景 | 处理方式 |
|------|----------|
| 标注完全在切片内 | 坐标平移，完整保留 |
| 标注跨越切片边界 | IoU > 0.5 保留，否则舍弃 |
| 标注被切成多块 | 每块独立保留（检测任务） |
| 极小小目标(<16px) | 扩大切片重叠率保护 |
| 分类任务 | 按切片分配，原图标签继承 |

### 5.2 核心设计决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 存储引擎 | JSON + YAML 文件 | 人可读、无需数据库、可版本控制 |
| 图片存储 | 原文件引用 + SHA-256 索引 | 不复制原始数据，去重靠哈希 |
| 标注格式 | JSON (XLABEL 格式) | 通用、可扩展、与现有兼容 |
| 切片引擎 | SAHI (成熟开源) | 已集成、高性能、支持多任务类型 |
| 训练引擎 | Ultralytics YOLO (子进程) | 成熟稳定、离线可用 |
| 推理引擎 | ONNX Runtime + TensorRT + OpenCV DNN | 本地推理、无网络依赖 |
| 任务编排 | 子进程 + 信号 | 不阻塞主 UI，无需消息队列 |
| UI框架 | PyQt6 | 已有资产，离线桌面应用标准选择 |

## 8. 附录：领域模型速查

```python
# TaskSpec — 任务定义（可随时修改）
class TaskSpec:
    family: Literal["classification", "detection_hbb", "detection_obb",
                    "instance_segmentation", "semantic_segmentation",
                    "keypoint", "anomaly_detection", "ocr"]
    labels: list[LabelDef]  # {id, name, color, shortcut}
    validation_rules: list[ValidationRule]  # 标注验证规则
    version: int  # 修改版本号

# Asset — 图片资产（导入时创建）
class Asset:
    id: str
    path: str  # assets/ 下的相对路径
    sha256: str  # 去重哈希
    attrs: ImageAttrs  # 尺寸/通道/位深/格式
    is_large: bool  # >2000px标记
    imported_at: datetime

# AnnotationDocument — 标注文档
class AnnotationDocument:
    asset_id: str
    shapes: list[Shape]  # 复用现有 Shape 模型
    status: Literal["unlabeled", "partial", "labeled", "reviewed"]
    updated_at: datetime

# TilePlan — 切片方案
class TilePlan:
    tile_width: int
    tile_height: int
    overlap_ratio: float  # 0.0-1.0
    edge_mode: Literal["strict", "crop", "pad"]
    label_split_policy: dict  # 标注切分策略

# SplitManifest — 数据切分清单（可复现）
class SplitManifest:
    strategy: Literal["random_by_asset", "random_by_tile", "manual"]
    splits: dict  # {"train": 0.7, "val": 0.2, "test": 0.1}
    random_seed: int
    asset_hashes: dict  # {asset_id: sha256} 用于复现验证
    assignments: dict  # {asset_id: "train"|"val"|"test"}

# Dataset — 数据集版本
class Dataset:
    id: str  # 时间戳命名
    split_manifest: SplitManifest
    tile_plan: Optional[TilePlan]
    created_at: datetime
    status: Literal["building", "ready", "failed"]

# Run — 训练实验
class Run:
    id: str
    dataset_id: str
    algorithm: str  # "ultralytics:yolov8m"
    params: dict  # 训练超参
    metrics: list[MetricPoint]  # 训练/验证指标
    best_metric: float
```
