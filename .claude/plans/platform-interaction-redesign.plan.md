## 一、行业标杆竞品分析摘要

### 1.1 MVTec HALCON Deep Learning Tool

| 维度 | HALCON 模式 |
|------|------------|
| **工作流** | 创建项目 → 导入图片+标注 → 数据切分 → 训练 → 评估 → 导出 (6步线性) |
| **图片导入** | 支持按文件夹结构自动分配标签(文件夹名=类别名)；支持手动导入 |
| **标注方式** | easyTouch 拖拽交互；ROI 定义；实时预览 |
| **超参数** | 数据切分在导入后才设置；训练参数在训练阶段独立配置 |
| **核心哲学** | **无代码、可视化、步骤线性但独立**；标注和导入可并行 |

### 1.2 阿丘科技 AIDI

| 维度 | AIDI 模式 |
|------|----------|
| **工作流** | 算法方案设计 → 图像标注 → 模型训练 → 模型优化 → 方案验证 → 部署 |
| **图片导入** | 内置标注工具，在方案设计阶段完成标注；支持增量添加数据 |
| **超参数** | 训练推荐集（基于历史成功案例智能推荐）；AI 缺陷生成器（AIDG） |
| **核心哲学** | **算法画布**（可视化拖拽编排）；小样本学习（20-30张即可）；增量训练 |

### 1.3 海康机器人 VisionTrain

| 维度 | VisionTrain 模式 |
|------|-----------------|
| **工作流** | 数据准备 → 数据标注(预标定+智能标定) → 训练(选择模型→配置参数→启动) → 评估 → 部署 |
| **图片导入** | 支持数据集导入裁剪；方案管理模式；可追加图片快速更新模型 |
| **超参数** | 训练参数推荐（基于样本特征自动推荐）；模型加密保护 |
| **核心哲学** | **三步训练**（极简）；二级界面（配置一目了然）；边缘学习（1-5张即可） |

### 1.4 三大平台共同特征

```
┌─────────────────────────────────────────────────────────┐
│                  深度学习平台通用交互模式                    │
├─────────────────────────────────────────────────────────┤
│  1. 工程/项目创建 ← 轻量，仅基本信息                         │
│  2. 数据导入       ← 独立步骤，支持多种来源                   │
│  3. 数据标注       ← 与导入解耦，可增量添加                   │
│  4. 数据预处理     ← 切分/增强/切片，独立可配置               │
│  5. 模型训练       ← 训推一体，参数推荐                      │
│  6. 模型评估       ← 量化指标 + 热力图可视化                  │
│  7. 模型部署/导出  ← 多格式导出，SDK集成                     │
└─────────────────────────────────────────────────────────┘
```

## 二、当前 X-AnyLabeling 问题诊断

### 2.1 用户旅程痛点地图

```
用户期望路径:
  新建工程 → 导入图片 → 配置参数 → 标注 → 训练 → 评估 → 导出

当前实际路径:
  新建工程(填名字+选任务类型+配标签) → ??? → 手动复制文件到assets/ → 回平台扫描 → 标注 → DataWorkspace配置超参 → 构建数据集
         ↑                                        ↑                              ↑
    一次性完成所有决策                      不存在导入功能                       参数隐藏在角落
```

### 2.2 核心问题清单

| # | 问题 | 严重度 | 当前表现 |
|---|------|--------|----------|
| P1 | **工程创建过重** | Critical | `NewProjectDialog` 强制一次性决定任务类型+标签，无法后改 |
| P2 | **无图片导入** | Critical | 代码库不存在任何图片导入功能，用户必须手动复制到 `assets/` |
| P3 | **超参数隐藏** | High | 切片/切分参数埋在 `DataWorkspace` 构建按钮旁，用户不可见 |
| P4 | **无数据预览** | High | 创建工程后无图片预览，一无所知开始空白工作区 |
| P5 | **任务类型不可逆** | Medium | 选错任务类型需要重建工程 |
| P6 | **标注与导入无关联** | Medium | 标注空间不知道图片从哪来、何时新增 |

### 2.3 架构耦合分析

```
当前紧耦合结构:
  NewProjectDialog ─── 创建工程 + 选任务类型 + 配置标签  [耦合度: 高]
  WorkbenchWindow  ─── 初始化所有Service + 扫描assets/  [耦合度: 高]
  DataWorkspace    ─── 显示图片 + 配置切片 + 配置切分 + 构建触发 [耦合度: 极高]
  LabelWorkspace   ─── 扫描assets/ + 嵌入标注控件        [耦合度: 中]

目标松耦合结构:
  ProjectCreator   ─── 仅创建工程容器 (名称+位置)
  ImageImporter    ─── 独立图片导入 (拖拽/批量/云) + 实时预览
  TaskConfigurator ─── 任务类型 + 标签 (可随时修改)
  PreprocessConfig ─── 切片/切分/增强 (独立可配置)
  LabelWorkspace   ─── 纯标注 (不关心图片来源)
  TrainWorkspace   ─── 纯训练 (消费已处理数据)
```

## 三、新方案：深度学习平台产品交互逻辑

### 3.1 设计原则

| 原则 | 来源 | 含义 |
|------|------|------|
| **渐进式披露** | AIDI + VisionTrain | 简单先呈现，复杂后展开 |
| **步骤解耦** | HALCON 6步模型 | 每步独立，可跳转、可回退、可重做 |
| **数据优先** | 三平台共识 | 先看到数据，再做决策 |
| **可逆决策** | 竞品对比得出 | 任务类型/标签/参数均可事后修改 |
| **预览驱动** | HALCON + VisionTrain | 每步提供可视化反馈 |
| **智能化推荐** | AIDI + VisionTrain | 基于数据特征自动推荐参数 |

Task 1.3: 新建 ImportService
  - 复制/移动文件到 assets/

## 七、风险与缓解

| 风险 | 可能性 | 缓解措施 |
|------|--------|----------|
| 现有项目兼容性 | High | 保留 V4 项目结构；新流程创建 V5 项目；V4 项目自动迁移 |
| 步骤解耦后状态一致性 | Medium | 步骤状态机集中管理；前置步骤修改时提示连锁影响 |
| 大图导入性能 | Medium | 异步导入 + 进度反馈；缩略图延迟加载 |
| 智能推荐准确度 | Low | 基于简单规则实现基线推荐 |
| NavigationBar 扩展性 | Low | 硬编码 8 步 (当前 6 步)，预留扩展槽 |
